!!! warning "Logging an 'APP Ticket'"
    Experiencing access rights issues or technical bugs in Salesforce? Please log an internal support request (APP Ticket) via the CISjira portal.

    > **Portal Path:** CISjira > Business Applications Support Portal > DX applications > DX support request

    1. **Issue Type:** Select 'Bug/Error'.
    2. **System:** Choose 'Salesforce'.
    3. **Component:** Select based on issue (e.g., 'Account Experience' for license/role issues).
    4. **Evidence:** You <u>must</u> provide a short description, steps to reproduce, and attach a HAR file & screen recording.

    <br>
