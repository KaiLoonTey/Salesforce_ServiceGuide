    Customer Credential Retrieval

    A step-by-step guide for assisting customers in finding their credentials through self-service or internal escalation, as well as managing name change requests on issued certificates.

    Retrieving Lost Credentials

    If a customer cannot find their certificate, follow these steps:

    1. Primary Method: Self-Service Direct the customer to the Credential Retrieval Tool. This allows users to find their certificates independently using their registered email address. → Open Retrieval Tool Guide

    2. Escalation Path 1: Internal Support If the customer is unable to locate their credentials using the self-service tool, please reach out directly to Kai Loon Tey for assistance.

    3. Escalation Path 2: Credentials Team Alternatively, forward the request to the global credentials team at tekla.credentials@trimble.com. Ensure you include the learner's email and the exact name of the course.

    Credential Name Change Requests

    Learners can now submit a name change request directly from their credentials in Accredible.

    Directing the Customer

    Trimble ID is the source of truth for learner information. If there is an issue with a learner’s name on a certificate, follow this two-step process:

    • Action 1: Instruct the learner to update their name in their Trimble ID. This corrects their profile in Learn for all future courses, but it will not retroactively update credentials that have already been issued.
    • Action 2: Once their Trimble ID is corrected, provide the customer with the external guide to submit a formal name change request for their existing credentials.

    → Customer Guide: How to Request a Name Change

    Internal Handling & Approvals

    Most standard requests (such as clear Western naming conventions) are handled centrally by the Global Credentials Team.

    If a request involves a local naming convention, a different language, or requires regional knowledge to validate, it will be assigned to the appropriate regional team.

    Check Your Email Filters

    You will only receive a notification from <tekla.credentials@trimble.com> when a specific name change request is assigned to you. Ensure these emails are not being filtered out. If you receive an assignment notification, you are responsible for reviewing, approving, or denying the request.

    Internal Reviewer Guide

    If you are unsure whether a request should be approved, follow the escalation guidance included in the internal process guide.

    → Internal Guide: How to Request and Manage Credential Name Changes
